# 여비 정산대장

출장신청서를 기준으로 관내·관외 출장 여비(일비·식비·숙박비·운임)를 「여비업무 처리기준」에 따라 자동 계산하고, 제출된 영수증의 OCR 인식 결과를 사람이 확인·수정한 뒤 규정상 인정금액과 비교해 초과·누락·중복을 검증하는 업무 흐름 검증용 프로토타입입니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 동작합니다. 별도 빌드나 서버가 필요 없는 정적 단일 페이지입니다.

## 범위

- 관내출장: 구간별 시간·거리 합산, 4시간 기준 판정, 관용차량/지정구간/내부행사 미지급 처리, 월 10만원 한도 검증
- 관외출장: 이동수단별 일비, 출발·도착시각 기준 자동 식비 판정, 지역별 숙박비 상한, 자가용 유가×거리÷연비 운임 계산
- 영수증: OCR 인식 시뮬레이션(사용처/날짜/금액/분류) → 사람 확인·수정 → 규정상 인정금액 비교, 초과·중복·증빙누락 경고
- 해외출장: 규정 미확정으로 계산 모듈만 구조적으로 분리해 둔 상태 (추후 확장 예정)

실제 OCR 엔진, 유가 데이터 연동은 되어 있지 않으며 시뮬레이션 값으로 흐름과 계산 로직을 검증하기 위한 목적입니다.
