# 여비 정산대장

출장신청서를 기준으로 관내·관외 출장 여비(일비·식비·숙박비·운임)를 「여비업무 처리기준」에 따라 자동 계산하고, 제출된 영수증의 OCR 인식 결과를 사람이 확인·수정한 뒤 규정상 인정금액과 비교해 초과·누락·중복을 검증하는 업무 흐름 검증용 프로토타입입니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 동작합니다. 별도 빌드나 서버가 필요 없는 정적 단일 페이지입니다.

## 범위

- 관내출장(재단 확정 기준): 구간별 시간·거리 합산, 4시간 기준 판정, 관용차량/지정구간/내부행사 미지급 처리, 월 10만원 한도 검증
- 관외출장(재단 확정 기준): 이동수단별 일비, 출발·도착시각 기준 자동 식비 판정, 지역별 숙박비 상한, 자가용 유가×거리÷연비 운임 계산
- 국외출장(「공무원 여비 규정」 별표3·별표4 참고값 — 재단 확정 규정 아님): 재단 직급↔여비등급 매핑, 국가/도시 지역등급 조회, 통화·환율 수동 등록, 일비/식비/숙박비상한/항공운임 자동 계산, 숙박비 초과지출은 자동지급이 아닌 사유·신청·승인 워크플로로 처리
- 관리자 설정 패널: 국외여비 관련 모든 기준값(여행자 등급표, 직급 매핑, 국가/도시 등급, 환율·식사차감·출귀국일계산·초과지급승인·증빙·정산기한 정책)을 "법령 기준 / 재단 자체 기준 / 미확정" 상태와 함께 화면에서 직접 수정 가능 — 코드 수정 없이 재단 확정 규정으로 전환 가능한 구조
- 영수증: OCR 인식 시뮬레이션(사용처/날짜/금액/분류, 국외는 통화 포함) → 사람 확인·수정 → 규정상 인정금액 비교, 초과·중복·증빙누락 경고

실제 OCR 엔진, 유가·환율 실시간 연동은 되어 있지 않으며 시뮬레이션/수동 입력 값으로 흐름과 계산 로직을 검증하기 위한 목적입니다. 국외출장 기준값은 재단 내부 규정이 확정되기 전까지 「공무원 여비 규정」을 참고한 초기값이며, 미확정 항목은 화면과 관리자 설정에 그대로 표시됩니다.
